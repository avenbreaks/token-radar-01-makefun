How to farm it

    Implied value = TVL × the category's FDV/TVL multiple (median market-cap-per-TVL of token-bearing protocols in that category) × 7-day growth × a track-record factor. It is this board's own claim, never a prediction that a token will launch.

    “Pre-token” means the protocol's DefiLlama record carries no token — not proof that it has none. Data: DefiLlama protocol snapshot, fetched 2026-11-14. Board built from that snapshot alone; no live prices.
